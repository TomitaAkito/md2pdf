Pfpdf GUIラッパー＆テンプレートビルダー 要件定義・実装仕様書

1. プロジェクト概要

Preferred Networks（PFN）が公開しているCLIツール pfpdf（Vivliostyle / Chromiumベース）を内部エンジンとして利用する、「GUIラッパー」としてのデスクトップアプリケーションを開発する。

MarkdownからPDFを直感的に生成できるジェネレーター機能に加え、PowerPointのようにマウス操作でPDFのテンプレート（表紙レイアウトや本文スタイル）を自作できる「テンプレートビルダー機能」を実装する。

2. システム構成・技術スタック

本アプリは pfpdf をラップするElectronアプリとして構築する。

プラットフォーム: Electron (クロスプラットフォームデスクトップアプリ)

フロントエンド: React, TypeScript, Tailwind CSS (UI構築)

状態管理: Zustand または React Context (テンプレートエディタの状態保持)

ドラッグ＆ドロップ: @hello-pangea/dnd または react-rnd (キャンバス上の要素配置用)

バックエンド (Electron Main Process): Node.js。pfpdf のソースコードは再実装・模倣せず、npm install pfpdf にてパッケージとして導入し、メインプロセスから呼び出す。

3. アプリケーションの2つの顔（コアモード）

用途に応じて2つのモードを切り替えて使用する。

3.1. ジェネレーターモード（PDF生成機能）

Markdownファイルを読み込み、テンプレートを適用してPDFを出力する日常利用モード。

入力: Markdownファイル（ドラッグ＆ドロップ対応）。

設定UI: Front Matterの主要項目（title, author, date 等）をGUIフォームで入力・上書き可能にする。

テンプレート選択: 公式テンプレート（academic, pfn 等）および、本アプリで自作したテンプレートを一覧から選
